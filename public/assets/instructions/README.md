# Sostituzione asset Beenacria

La gallery usa placeholder premium realizzati con CSS per non dipendere da immagini esterne.

Quando saranno disponibili foto reali:

1. Inserisci immagini ottimizzate in `public/assets/gallery`.
2. Preferisci formati `.webp` o `.avif`, larghezza 1200-1800px.
3. Aggiorna `galleryItems` in `data/content.ts` aggiungendo un campo immagine se vuoi passare da placeholder CSS a immagini reali.
4. Mantieni alt text descrittivi: vasetto, api, fioriture, paesaggio, mani al lavoro.
5. Sostituisci telefono, email e WhatsApp placeholder nei componenti contatto.

Il logo in pagina è un SVG disegnato a codice ispirato al riferimento allegato, così resta nitido e animabile.
